# Недостатки текущей модели

## Контекст

Текущая модель уже сфокусирована на кулинарии, но пока использует демонстрационный календарь и не знает твоих реальных продаж. Главный риск - делать заказ по среднему шаблону без остатков, списаний и сезонности.

## Что стоит добавить

1. Реальные прошлые периоды
   Нужны продажи или заказы по каждой позиции за несколько последних периодов.

2. Остатки
   Без текущего остатка сервис не может сказать, сколько именно дозаказать.

3. Списания
   Списания нужно прибавлять к спросу, но отдельно показывать как риск перепроизводства.

   Текущая выгрузка актов списания за июнь-июль содержит список позиций в акте, но не дает штучное количество по каждой позиции. Поэтому сейчас модель считает частоту попаданий позиции в списания. Для точного расчета потерь нужен файл формата:

```text
date,sku,name,waste_quantity,waste_sum,reason
```

4. Кратность заказа
   Для каждой позиции нужна партия: поштучно, коробка, лоток, гастроемкость или другая кратность.

5. Причина рекомендации
   Каждая строка заказа должна объяснять себя: расчет по истории, риск нехватки, риск списаний, нет истории.

6. Поправки дня
   День недели, погода, акции и события рядом должны быть ручными признаками на первом этапе.

7. Недобор целевой витрины
   Цель на день - 34 позиции: 8 супов, 9 вторых, 17 завтраков и салатов. Если в данных не хватает безопасных SKU без высокого риска списаний, сервис должен показывать недобор и резервные подмены, а не заполнять меню нерелевантными категориями.

8. Сроки годности готовых SKU
   Файл `data/local/Хранение и сроки годности, реализации.xlsx` используется для сверки сроков 2-3 дня. В нем много правил по сырью и полуфабрикатам, поэтому для точного автоподбора нужен отдельный справочник готовых позиций:

```text
sku,name,shelf_life_days,storage_mode,source_comment
```

## Приоритет ближайших итераций

1. Принять твой список позиций и прошлые заказы.
2. Привести данные к CSV/JSON-формату.
3. Подключить `src/domain/culinary.py` к веб-панели.
4. Показать рекомендуемый заказ на 2 дня с причинами.
5. После этого перейти к отдельной модели отпека по выпечке.
