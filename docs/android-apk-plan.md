# Android APK

## Статус

Android APK сейчас не является основной формой продукта. Активная версия сервиса развивается как локальная веб-панель для заказов кулинарии.

Существующий Android scaffold можно оставить как технический эксперимент, но не стоит развивать его до тех пор, пока логика заказов кулинарии не будет проверена на реальных данных.

## Когда APK снова понадобится

APK имеет смысл вернуть в приоритет, если нужен:

- быстрый ввод остатков с телефона;
- офлайн-режим на точке;
- локальные уведомления о заказе кулинарии;
- сканирование накладных;
- планшетный режим для управляющего.

## Что нужно изменить в Android-версии

- Убрать старые демо-данные.
- Заменить экран на заказы кулинарии: обеды, салаты, роллы, супы и горячие блюда.
- Добавить двухдневный цикл заказа.
- Добавить причины рекомендации: расчет по истории, риск нехватки, риск списаний, нет истории.
- После этого отдельным модулем добавить отпек выпечки.

## Текущий приоритет

1. Стабилизировать веб-панель.
2. Принять реальные прошлые периоды по кулинарии.
3. Подключить расчет рекомендаций к веб-панели.
4. Проверить модель на фактических заказах.
5. Затем перейти к выпечке.
