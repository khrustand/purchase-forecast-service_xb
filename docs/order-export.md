# Excel и отправка заказа

## Скачать текущий расчет

В разделе «Заказы» под сводкой ближайшего заказа нажмите «Скачать Excel: кулинария + ТТ».
Для другого периода сначала выберите его дату.

В книге два листа:

- **Поставка** — дата поставки и дедлайн вверху, затем артикул, название, категория
  и общее количество порций к заказу.
- **Кулинария ТТ** — артикул, название, категория, выпуск по дням и итог.
  Продукция ТТ готовится к открытию и годна только в день приготовления.

Каждый лист настроен на одну страницу А4. Все количества включают порции питания
сотрудников из расчета. Если в названии сырников указано «2 шт.», это одна
порция из двух сырников. Неизвестный артикул остается пустым. Отсутствие прогноза
обозначается «нет данных», реальный ноль сохраняется.

Итоги — формулы Excel с сохраненными результатами. При ручном изменении
количеств суммы пересчитываются. Файл использует количества из расчета заказа
без повторного применения прогнозных коэффициентов.

Скачивается снимок показанного расчета, без нового обращения к отчетам или погоде.
После изменения исходных данных обновите страницу для нового файла. Снимки живут
в памяти конкретного сервера до суток, не более 64 штук. После перезапуска сервера
или вытеснения снимка старая ссылка выдаст понятное предложение обновить страницу.
Доступ к файлу защищен той же авторизацией, что и заказ. Файл не сохраняется в
общедоступной папке сервера.

## Что требуется для рассылки

Рассылка пока не включена. Для нее нужно отдельно определить получателей,
поставляемый лист или полную книгу и правило отправки.

**Email:** адрес получателя, адрес и провайдер отправителя, разрешенный этим
провайдером способ входа (пароль приложения или OAuth), SMTP-сервер/порт/TLS либо
почтовый API. SMTP поддерживается стандартной библиотекой Python:
[документация smtplib](https://docs.python.org/3/library/smtplib.html).

**Telegram:** создать бота через
[@BotFather](https://core.telegram.org/bots/features#botfather), сохранить токен
локально, получить `chat_id` получателя. Для личного чата получатель сначала
запускает бота, для группы бота добавляют и разрешают отправку документов.
Файл передается методом
[sendDocument](https://core.telegram.org/bots/api#senddocument), идентификатор чата
можно получить из [getUpdates](https://core.telegram.org/bots/api#getupdates).

Секреты хранятся в локальных настройках или secret manager, не в Excel, Git или
сообщениях чата. Следует выбрать отправку кнопкой после проверки заказа или
расписание до дедлайна D−2, 18:00 МСК. Рекомендуемый первый этап — кнопка и журнал
результатов с защитой от повторной отправки. Для расписания процесс должен
работать в назначенное время на включенном компьютере или сервере.

## Технические детали

`GET /orders/export.xlsx?snapshot=TOKEN` возвращает XLSX с `Content-Disposition:
attachment` и `Cache-Control: no-store`. Неизвестный или истекший снимок — HTTP 410.
Экспорт использует стандартную библиотеку Python, новых зависимостей в приложении
нет. Два листа имеют закрепленные заголовки, области печати и формулы итогов. Загруженные
названия записываются как буквальный текст, включая строки, начинающиеся с `=`.

Поддерживаемые entry points используют `DashboardServer`, который хранит кэш.
При размещении на нескольких процессах нужны общие снимки либо привязка запросов
к одному процессу. Текущий локальный запуск использует один процесс с потоками.
