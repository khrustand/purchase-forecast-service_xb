# Архив: личный профиль тела

Этот документ относится к прежней идее проекта для личных домашних закупок и питания. В текущей версии сервис переориентирован на аналитику предзаказов для кофейни, поэтому антропометрия, калории, профиль питомца и домашние сценарии больше не являются активной частью продукта.

Документ оставлен как архивный след решения. Для текущей разработки использовать:

- [product-scenarios.md](product-scenarios.md)
- [cafe-procurement-model.md](cafe-procurement-model.md)
- [product-gaps.md](product-gaps.md)
